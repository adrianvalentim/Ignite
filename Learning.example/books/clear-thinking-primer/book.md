# A Primer for Clear Thinking

## Current State

The learner can separate claims from reasons and is beginning to notice when an
argument depends on an unstated bridge. The next useful pressure point is
counterexample generation.

## Key Insights So Far

- A reason is not merely a sentence placed after a claim; it must change the
  probability that the claim is true.
- Hidden assumptions often do the real work in an argument.

## Difficulties

- Naming assumptions without making them broader than the original claim.
- Designing counterexamples that test the exact claim instead of a nearby one.
